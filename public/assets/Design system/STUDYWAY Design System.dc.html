01

Спокійна основа, один акцент

Чорний текст на білому, сірі поверхні. Синій — тільки для дії та статусу, ніколи як фон великих блоків.

02

Повітря замість рамок

Блоки розділяємо відступами й радіусами, а не обведеннями. Межа — 1px rgba(0,0,0,.04), майже непомітна.

03

Палець перший

Мінімальна ціль дотику — 48px, на мобільному кнопки та поля вищі, ніж на десктопі.

Токени

Кольори

Дев'ять кольорів на весь продукт. Ключові — з поточної теми сайту; статусні кольори замінюють службові ключові слова green / red / yellow, які були в коді.

{{ c.name }} {{ c.hex }} {{ c.use }}
Роби

Синій — на кнопці дії, активному пункті меню, маркерах списку, лічильниках. Один синій елемент на екран у полі зору.

Не роби

Не використовуй чистий #000 для великих площ фону — для темних секцій є #1A1A1A. Не додавай нових відтінків синього.

Токени

Типографіка

Futura PT, два накреслення: Book (400) для тексту і Medium (500) для заголовків та акцентів. Ваги 600 і 700 у системі мапляться на Medium — псевдожирний вимкнено. Базовий текст 14px на мобільному, 16px від 992px. Через відкриті форми Futura міжлітерний інтервал заголовків тримаємо на -.01em, а капслок-надзаголовки — на .12em.

{{ t.token }} {{ t.mobile }} {{ t.desktop }} {{ t.weight }}
{{ t.sample }}
Міжрядковий інтервал: 1.15 для H1–H2, 1.2 для H3–H4, 1.5 для тексту, 1 для кнопок і полів.
Довжина рядка — до 70 символів. Абзац у контенті обмежуємо 620–720px незалежно від ширини екрана.
Капслок — тільки для надзаголовків 13px із letter-spacing .12em. У заголовках не використовуємо.
